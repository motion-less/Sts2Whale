# 业务文档

> 这个产品是什么、对谁有用、跑起来是什么样、边界和成本在哪里。
> 想改代码看 [TECH.md](TECH.md)；皮套与语音细节看 [AVATAR.md](AVATAR.md)。

## 1. 一句话

**Sts2Whale（鲸鱼爬塔）** 是《杀戮尖塔 2》的一个 mod，把三个「大脑」和一个「皮套」编进同一个 DLL：

| 部分 | 管什么 |
|---|---|
| **战斗路线求解器** | 战斗内出牌：搜世界线、挑最优行动序列 |
| **全局战略助手** | 局外：选路、选牌、商店、营火、事件 |
| **鲸鱼娘（LLM）** | 说话：用角色卡口吻把决定讲给玩家，兜底不认识的界面 |
| **VTube Studio 皮套** | 把台词和战斗事件变成表情、动作、口型 |
| **直播弹幕互动** | 挑观众弹幕回一句（默认最多 3 条/分钟） |

玩家只要开着游戏：局外助手自己点，战斗求解器自己打，鲸鱼娘在字幕条里解说
（底部居中、白字黑描边、背景透明、可拖动），VTS 里的 Live2D 皮套同步说话、皱眉、举锅盖、被打歪。
人（或另一个 AI agent）可以通过 `127.0.0.1:47821` 的 HTTP 接管任意一步。

## 2. 目标用户与场景

| 用户 | 想要的 | 这个 mod 给什么 |
|---|---|---|
| 想「看 AI 打牌」的玩家 | 不用操作，看有个性的角色爬塔 | 全自动 + 拟人解说 + 会动的皮套 |
| 虚拟主播 / 内容创作者 | 直播素材，角色有画面、有声音 | 游戏进程内驱动 VTS，可当直播画面的一部分 |
| 想研究 AI 决策的人 | 可观测、可干预 | 每步都有日志/接口，随时 `/request` + `/respond` 接管 |
| 想做自动化的开发者 | 稳定的游戏内驱动层 | 一套语义化 HTTP（不点坐标、不截图） |

**不做什么**：不做联机作弊、不扫内存、不替玩家跳过游戏内容 —— 所有操作都走游戏自己的按钮和命令。

## 3. 玩家能看到什么

1. **一条可拖动的字幕**：一句话带理由或数字；默认底部居中，像电影字幕 —— 背景透明、白字带黑描边。
   一行最多 40 字，超了自动折行、气泡变高；**不截断**。按住拖动换位置，松手即记住（换分辨率也不跑丢）。
2. **没有助手窗口**：求解器分析层、战略面板、循环爬塔浮动条默认隐藏（F8 可临时调出面板）。
3. **决定都有解说**：
   - 选牌 → 「拿剑柄打击 前期缺输出」
   - 选路 → 「走右边 商店能删牌」
   - 战斗 → 「已观测 12,345 条世界线（678 条每秒）」
   - 结束 → 「收工，一滴血没掉，还剩 80」
4. **皮套会演**：说话对口型；打人「黑脸」；被咬一口「＞＜」；掉多了「流泪」；
   有格挡头顶「钢盆」；求解器算牌时「圈圈眼」；被打到时整个人向右歪一下再弹回来。
5. **打不过会认输**：「拼尽全力无法战胜，投子认负」→ 自动收尾 → 开下一把（默认铁甲 A10）。
6. **死了/赢了自动续跑**：建筑师处结束 → 收尾 → 自动开下一把。

## 4. 一局的完整生命周期

```
启动游戏
  → 自动接管（局外助手 enable）
  → 主菜单（有存档先继续）
  → 逐层：地图选路 → 房间（战斗/事件/商店/营火/宝箱）→ 奖励
  → 战斗：求解器接管（blocking=true）→ 打完交还 → 奖励
  → 三层 Boss → 建筑师（游戏结束）
      → 关助手 → 关地图 → 收尾「继续 → 主菜单」
      → 新局：铁甲 A10 → 助手重新打开
  （中途判定必死：认输 → 结束回合 → 同上收尾）
```

退出游戏用 `POST /quit`：先存档回主菜单，再走游戏自己的 `NGame.Quit()`。

## 5. 三个「谁来决定」的边界

| 场景 | 决定方 | 说明 |
|---|---|---|
| 战斗内出牌、药水、目标 | 求解器 | 桥接不插手（`blocking:true`） |
| 战斗内弹出的选牌 | 求解器 | 它有自己的模拟 |
| 局外一切选择 | 战略助手 | 它 enable 时 `/request` 返回 `pending:null` |
| 助手暂停/卡住/不认识 | 鲸鱼兜底 | 按策略代答，或按 `min` 补齐 |
| 收尾、认输、开下一把 | AutoLoop | 关助手 → 走游戏自己的按钮 → 重开 |
| 玩家手动干预 | 玩家 | F8 看面板；`POST /strategist {"on":false}` |

**硬门禁**：agent 走路或选牌前 25 秒内必须说过话，否则接口拒绝（`need_reason`）——
逼出「解说」而不是静默操作。

## 6. 能调的旋钮

| 想改什么 | 改哪里 |
|---|---|
| 说话风格 | 设置页「角色卡」直接编辑（保存即生效），或改 `persona.md` |
| 用哪个模型 / key | 设置页「鲸鱼娘的嘴」，或改 `llm.json`（改完 `POST /whale/brain/reload`） |
| 关掉模型说话 | `llm.json` 的 `enabled:false`（只剩本地垫话） |
| 皮套表情映射 | `vts.json` 的 `emotions`（见 [AVATAR.md](AVATAR.md)） |
| 换 TTS 声音 | `vts.json` 的 `speech.edgeVoice`（`zh-CN-XiaoyiNeural` / `zh-CN-XiaoxiaoNeural`） |
| 关掉摆头/倾斜 | `idleSway:false` / `hitTilt:false` |
| 开/关弹幕 | 设置页填房间号 → 点「打开弹幕页」；或 `live.json` |
| 下一把角色/难度 | `STS2_AUTO_CHARACTER` / `STS2_AUTO_ASCENSION` |
| 关掉自动续跑 | `STS2_AUTO_NEXT_RUN=0` |
| 关掉助手自动接管 | `STS2_STRATEGIST_AUTO=0` |

## 7. 成本模型

- **说话**：每次一次模型调用，system 是整份 `persona.md`（约 1.6k token），输出十几字。
  prompt 不变，第二次起基本全命中缓存，每次约 230 个新 token。
  一局（30 分钟、100+ 次播报）**约 0.15 元**（有缓存）到 0.4 元（无缓存）。
- **战斗求解**：本机 CPU，不花 API 钱；战略助手也是本机启发式。
- **语音**：Edge 在线语音免费，不产生费用；代价是每句 1~2 秒延迟（瓶颈在微软接口）。
- **皮套**：VTube Studio + 本地模型，零成本。
- **弹幕**：一个浏览器进程（约 150–250 MB 内存），无网络费用。
- 真正贵的是「外部 agent」在轮询 `/request`，那是另一半账。

## 8. 什么算「做对了」

1. 玩家开局后不需要碰键鼠，一局能自己打完。
2. 每次值得说的决定，气泡里都有带理由的一句话。
3. 卡住不超过「5 秒探测 + 一次兜底动作」，且必留日志。
4. 死/赢之后能自己接上下一把，助手是开着的。
5. 玩家随时能接管：`/request` 看到待决定项，`/respond` 替他答。
6. 皮套跟着演：说话有口型，打人/挨打/格挡/思考都有对应表情，被打到会歪。
7. 语音/弹幕/皮套任一缺失，其他功能照常 —— 缺什么只降级对应的那一块。

## 9. 已知边界

- 角色主要验证过**铁甲战士**（战略助手策略库以它为主）。
- 建筑师（最终 Boss）战斗不归 mod 管：见到即视为本局结束。
- 求解器不保证 100% 赢，「认输」是设计而非 bug。
- 新遗物/新事件可能没适配，兜底会按 `min` 瞎选一个能推进的选项。
- 皮套的头部绑定很弱（注入 90° 只偏几像素），受击倾斜是**整模旋转**，不是真的扭头。
- 语音走 Edge 在线接口（非官方），微软改协议就可能失效；届时回落到命令行 `edge-tts`，
  再不行只动嘴不出声。
- macOS 的语音口型按真实音频包络算；Windows / Linux 没有系统音频转换工具，
  按字数估包络 —— 有声音、嘴也动，但和声音不完全对齐。
